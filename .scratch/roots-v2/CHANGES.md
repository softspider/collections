## (б) Решения, требующие подтверждения автора

Каждое решение — рекомендация, применённая в тексте. Альтернатива указана для выбора.

| ID | Решение в тексте | Альтернатива |
| --- | --- | --- |
| R1 | Перемещение/копирование между срезами — только в пределах одной исходной области; меняют только пользовательские теги. Копия получает принадлежность области: коллекция — только эта коллекция; подборка — вхождение в конце ручного порядка; пространство — без коллекций и подборок. Перенос между коллекциями — включение плюс перемещение. Удалена часть открытого вопроса об «операциях с элементами нескольких коллекций»; остаток сформулирован как групповые операции | Межобластные операции, явно изменяющие принадлежность (например, «переместить в срез коллекции B» = включить в B, исключить из A, заменить теги) |
| R2 | «Уплощение»: пользовательский срез хранит исходную область и объединённый пользовательский фильтр, ссылок на срезы нет. Следствие: открыв такой срез, пользователь может расширить фильтр за пределы прежнего выбранного среза, так как областью теперь служит объект | Ссылочная семантика: срез хранит ссылку на базовый пользовательский срез; каскад удаления и изменения распространяется на косвенные зависимости |
| R3 | Раздел «Создание и изменение объектов». Отдельно требует подтверждения: **удаление рабочей области удаляет все её объекты**; тип коллекции меняется только у пустой коллекции; повторное включение в коллекцию состав не меняет | Удаление рабочей области с выгрузкой или переносом объектов; смена типа коллекции с исключением несовместимых элементов |
| R4 | Порядок по умолчанию вне подборок, признаки сортировки, сохранение сортировки в пользовательском срезе — открытые вопросы; правило «сохраняются только область и фильтр» оставлено | Задать порядок по умолчанию сейчас (например, по времени добавления) и сохранять сортировку в пользовательском срезе |
| R5 | Проверку выполняет исполнитель; при программном вызове — подтверждение вызывающей стороны или автоматическая проверка. При перемещении с изменением содержимого — выбор «применить / копия (= копирование между теми же срезами) / отказ». Выбор относится к правке целиком: при копии все изменения правки получает копия | Запрет изменения содержимого в ходе перемещения (только отказ); раздельное применение изменений тегов к оригиналу и содержимого к копии |
| R6 | Глоссарий включает служебные теги; пользователю доступна только пользовательская часть; служебный тег удаляется из глоссария вместе с объектом | Служебные теги вне глоссария как отдельное измерение приложения (тогда пространство определяется не только глоссарием, и это нужно отразить в ТП) |
| R7 | В ТП: идентичность тега, инвариант глоссария, минимальная модель навигации (узел — фильтр в области; порядок строгим включением, DAG; узлы без сохранения; приложение ведёт именованные узлы). Правила изменения глоссария, затрагивающие разметку, отнесены к приложению | Перенести подробную модель навигатора в отдельный документ ветви платформы и сослаться на него из ТП |
| R8 | Срез определяется областью и фильтром (полным фильтром), состав производен; коллекция — объект; подборка — последовательность вхождений; пользовательский срез — запись условий; каждый элемент рабочей области — элемент её пространства | Срез как множество (состав) с отдельным понятием «цель операции» для перемещения |
| R9 | Термины и формулировки по замечанию 10 | — (редакционные) |
| R10 | Правила — в прикладных разделах; «Применение платформы» — только соответствие и ссылки | Наоборот: сосредоточить технические соответствия в «Применении», убрав их из прикладных разделов |
| С1 | Собственное: «Элемент принадлежит подборке, если в ней есть хотя бы одно его вхождение» добавлено в «Подборки» (раньше выводилось из раздела удаления и «Служебных тегов») | Оставить неявным |
| С2 | Собственное: служебный тег создаётся вместе с коллекцией/подборкой и при её удалении удаляется и из глоссария (вывод из R6) | Сохранять служебный тег удалённого объекта в глоссарии как исторический |
| С3 | Собственное: выбор коллекций при создании копии правкой выполняет «исполнитель», а не «пользователь» (вывод из R5 для программных вызовов) | Выбор коллекций только в интерфейсе; при программном вызове копия без коллекций |
| С4 | Собственное: у элемента при создании можно сразу назначить теги и включить в коллекции; способы создания (импорт) задаёт спецификация выпуска | Создание только «пустого» элемента с последующими операциями |
| С5 | Собственное: пользовательский срез — «прикладная запись, а не объект платформы»; при открытии исходная область задаёт предварительный фильтр, пользовательский — текущий (вместо прежней фразы ИП:452-453) | — |
| С6 | Собственное: удаление пользовательского тега — открытый вопрос (расширение «Глоссарий тегов» предлагает архивирование и объединение, но в корень это не переносилось) | Ввести в корень архивирование как базовое правило |

## Проверочные примеры

1. **Перемещение *e* из среза коллекции A в срез коллекции B.** Единой операцией не выполняется: срезы
   разных исходных областей. Нужно включить *e* в B (принадлежность A сохраняется; исключение из A —
   отдельное действие), затем в области B переместить *e* между её срезами. Перемещение внутри A меняет
   только пользовательские теги, *e* остаётся в A и непосредственно принадлежит целевому срезу A.
2. **Копирование в срез подборки.** Копия получает пользовательские теги полного фильтра целевого среза,
   в подборке создаётся вхождение копии в конце ручного порядка; коллекций и других подборок у копии нет;
   поэтому она непосредственно принадлежит целевому срезу. Если нужно изменить содержимое, правки
   относятся к копии без дополнительного выбора.
3. **Удаление подборки П при сохранённом S2** (S2 сохранён при области «срез `{джаз}` подборки П»).
   S2 хранит исходную область П и объединённый фильтр `{джаз, …}`, значит связан с П. Перед удалением П
   пользователь видит S2 в списке связанных; подтверждение удаляет П вместе с S2, либо пользователь
   заранее выбирает для S2 другую область.
4. **Правка: изменён текст и снят тег `черновик`, выбрано «создать копию».** Выбор относится к правке
   целиком: копия получает изменённый текст и пользовательские теги оригинала без `черновик`; оригинал
   не меняется и сохраняет `черновик`. Коллекции копии выбирает исполнитель; при работе из подборки копия
   заменяет выбранное вхождение.
